# Tugas Mandiri Pertemuan 03

## Tujuan

Tugas mandiri ini bertujuan untuk memahami perbedaan penggunaan component CSS dan utility-first CSS, membuat layout responsif, memahami autentikasi dan otorisasi JWT, serta memahami hash password dengan bcrypt.

## Tugas Mandiri

Tugas mandiri pada Pertemuan 03 terdiri dari lima tugas:

1. TM1 - Perbandingan Component CSS dan Utility Classes
2. TM2 - Layout Responsif dengan Tailwind CSS
3. TM3 - Matriks Hak Akses dan Role
4. TM4 - Analisis JWT
5. TM5 - Analisis Hash Password dengan bcrypt

## TM1 - Perbandingan Component CSS dan Utility Classes

### Tujuan

Membandingkan pembuatan kartu profil menggunakan component CSS dengan utility-first CSS menggunakan Tailwind CSS.

### Cara Menjalankan

Buka file berikut menggunakan browser atau Live Server:

- `frontend/web/tugas-mandiri-1-component.html`
- `frontend/web/tugas-mandiri-1-utility.html`

Kedua file menggunakan data profil yang sama dan dapat diuji pada ukuran layar desktop maupun 360px.

### Hasil

Berhasil membuat dua versi kartu profil mahasiswa dengan tampilan yang sama. Versi pertama menggunakan CSS pada tag `<style>`, sedangkan versi kedua menggunakan utility classes Tailwind CSS.

Kedua versi dapat ditampilkan dengan baik pada ukuran layar desktop dan 360px tanpa horizontal scroll.

Perbandingan implementasi dan hasil pengujian dijelaskan pada:

`frontend/web/tugas-mandiri-1-css-compare.md`
